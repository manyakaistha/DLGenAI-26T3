No raw data or GPU benchmark is required for these checks.
- Assessment protocol pins SMP 0.5.0 / PyTorch 2.8.0 / torchvision 0.23.0 and explicit decoder settings. Q2 freeze is only for counting. Q8 compares the same ResNet-34 U-Net with random versus ImageNet encoder initialization and matched decoder/head starts. Q9 changes backbone. Both use the saved Milestone 2 split, grayscale native 128×800 [0,1] input, no augmentation, five float32 epochs, trainable encoders and threshold >=0.5 without area filtering.
- Score uses Milestone 1's 70/20/10 foreground/false-positive/empty components. Loss is mean BCE plus a single batch/channel/spatial Dice ratio. Eval-mode train/validation losses define the gap. Ties and unmeasured CUDA/OOM outcomes are explicit; no model outcome is promised.
- PR #4 corrections remove assessment-identical worked answers and competition statistics, use separate toy examples, distinguish the first decoder-skip mismatch from a full-canvas deficit, correct bias and BatchNorm explanations, and distinguish a high Dice loss from its probability/logit gradients. Compound loss is a testable choice, not universally superior. Illustrations do not establish benchmark results.
- Legacy CPU walkthrough is a synthetic learning aid, not the Q8/Q9 benchmark. Notebook and script share 0.5 BCE + 0.5 Dice; preserve paired code cells and empty outputs when editing.
