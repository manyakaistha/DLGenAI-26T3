# Deployment Guide (Hugging Face Space)

Student-facing, 20-minute guide: turn trained weights into a Gradio app on a free-tier ZeroGPU Hugging Face Space. Upload an image, get predicted masks overlaid. Published at `/deployment/` and listed first under Live Session Resources.

- Source: `docs/deployment_guide/` — `README.md` (overview), `01_prepare.md`, `02_publish.md`, `03_have_a_pth.md` (what is inside a .pth; two-line notebook fix; converter; error table), `convert_to_weights.py` (standalone converter, served as a download, not in the zip), `figures/` (3 synthetic PNGs), `space_template/` (`app.py`, `model.py`, `requirements.txt`, `README.md` Space header).
- Builder: `scripts/build_deployment_session.py` (reuses `build_live_session.render`; zips `space_template/` into `surface_defect_space.zip`, the page's download). Hub entry is the first item of `SESSIONS` in `scripts/build_student_hub.py`; `build_student_pages.py` calls the builder. Local: `uv run --no-project scripts/build_deployment_session.py --output runs/deployment_preview`.
- Figures: `uv run --no-project scripts/generate_deployment_figures.py` (synthetic only; no competition data).
- Template contract: 4 independent sigmoid channels (a–d), grayscale 800×128 input, `THRESHOLD`, `preprocess()` flagged as "must match training"; state_dict `weights.pt` loaded with `map_location="cpu"` then `.to(device)`. Gradio pinned via `sdk_version: 6.31.0`; Space README also sets `python_version: "3.12.12"`.
- **Hardware (corrected 11 Nov 2026):** free accounts cannot pick CPU basic (needs PRO); Gradio Spaces run on **ZeroGPU**. ZeroGPU needs a `@spaces.GPU` function (template: `try: import spaces; gpu=spaces.GPU(duration=20) except ImportError: gpu=identity`), model on `cuda` at module level, a CUDA PyTorch build (`torch>=2.8.0`, no CPU index line) and Python 3.12.12 or 3.10.13. Free limits: 2 ZeroGPU Spaces, account >30 days with verified email, daily GPU quota 5 min logged-in / 2 min anonymous. Without the decorator the Space fails with "No @spaces.GPU function detected during startup".
- Verified 11 Nov 2026: template launched locally with Gradio 6.31.0, called through `gradio_client`, returned an 800×128 RGB overlay. Full-site build checks 191 pages.
- The page has no Ask-AI controls. Published to GitHub Pages at /deployment/ on the user's instruction (11 Nov 2026).
- `convert_to_weights.py` verified 11 Nov 2026 on five save forms (state_dict, training checkpoint, `module.` prefix, whole pickled model, TorchScript): all load into a fresh model with identical outputs; a missing class gives a plain-language error.
- `01_prepare.md` explains `app.py` in eight numbered sections (imports, @gpu marker, settings, load once, preprocess, predict 6a–6c, Interface, launch) for beginners (added 11 Nov 2026).
- The student homepage also has a third card (Deploy Your Model) linking to /deployment/; defined in the `index.html` entry of `directories` in `scripts/build_student_hub.py`.
