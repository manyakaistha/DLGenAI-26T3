4 · Brightness is one clue; arrangement is another

Core question: what can an intensity measurement establish, and what information does it leave out?

A bright patch might be an annotated region, an ordinary reflection or a change in illumination. A region can also differ through the arrangement of its light and dark pixels while keeping the same average brightness. We need to separate these possibilities before proposing a transform or a model.

This chapter is a standalone study guide. Follow the Core sections first; the optional sections explain statistics and spatial features more deeply. All numbers and patterns below are invented teaching examples. They do not identify any industrial defect class or give measured results for the practice dataset.

Core · Begin with a registered image and mask

An intensity is a measured value at a location. A binary mask is a membership decision at that location. To compare foreground with background, their coordinates must agree. First display the image, the individual class mask and their overlay. A transposed or shifted mask produces convincing statistics about the wrong pixels.

For RGB images, specify what quantity you measure. Red-channel intensity, three separate channel distributions and a declared grayscale conversion are different choices. Averaging RGB channels is a possible teaching feature; it is not a universal definition of luminance. Keep the choice fixed across examples.

Also define background. For class A, mask_A == 0 includes any locations belonging to other classes. Alternatively, “no annotation of any class” uses the complement of the union of all class masks. A nearby ring around a region measures local surroundings, whereas the entire image includes distant lighting conditions. None of these definitions should be silently substituted for another.

A minimal single-channel extraction is:

import numpy as np

# intensity and mask refer to the same image grid.
intensity = np.array([[20, 30, 50], [40, 60, 80]], dtype=np.float32)
mask = np.array([[0, 0, 1], [0, 1, 1]], dtype=bool)
assert intensity.shape == mask.shape
inside = intensity[mask]
outside = intensity[~mask]
print(inside)   # [50., 60., 80.]
print(outside)  # [20., 30., 40.]

Boolean indexing selects values; it does not keep their two-dimensional arrangement. That is appropriate for a histogram, but it has already discarded spatial information. If either group is empty, report that the comparison is unavailable instead of calculating a mean from no observations.

Core · Mean, variance and standard deviation answer different questions

For values \(x_1,\ldots,x_n\), the mean is

\[ \bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_i. \]

It gives the average intensity. Variance measures squared deviations from that average. For a complete toy population,

\[ \sigma^2=\frac{1}{n}\sum_i(x_i-\bar{x})^2, \qquad \sigma=\sqrt{\sigma^2}. \]

Take [30, 40, 50]. Their sum is 120 and mean is 40. Deviations are [-10, 0, 10]; squared deviations are [100, 0, 100]. Population variance is 200/3 ≈ 66.667, and population SD is about 8.165. Variance has squared intensity units; SD returns to intensity units.

When describing a sample with the usual sample-variance convention, divide by n−1 instead. For these same three numbers, sample variance is 200/2 = 100 and sample SD is 10. These are different quantities, not contradictory answers. State which one you used.

values = np.array([30, 40, 50], dtype=np.float64)
print(values.mean())            # 40
print(values.var(ddof=0))       # population variance: 66.666...
print(values.std(ddof=1))       # sample SD: 10

ddof changes the divisor from n to n−ddof. A sample SD needs at least two values. NumPy's variance documentation explains this convention. Converting to floating point before arithmetic also avoids unsigned-integer subtraction wrapping around instead of producing a negative deviation.

Core · A histogram keeps counts and loses coordinates

A histogram counts how many values lie in each intensity interval, called a bin. If one group contains 100 pixels and another contains 1,000, raw bin counts mostly reveal that size difference. For distribution comparison, divide each group's bin counts by its own total and state that you are showing proportions.

Use the same bin edges and intensity range for both groups. Otherwise a bar in one plot may describe a different interval from a bar in the other. Very wide bins hide structure; very narrow bins can make a small sample look irregular. Show sample sizes alongside the plot.

Equal means do not imply equal histograms. [20,40,60] and [0,40,80] both average to 40, but the second has more spread. [0,0,60,60] and [30,30,30,30] both average to 30, yet one is split between extremes and the other is constant. A mean difference of zero alone cannot establish that two groups are visually indistinguishable.

Now consider a stronger equality: the entire histogram is identical.

Pattern A                 Pattern B
0   0   255 255            0   255 0   255
0   0   255 255            255 0   255 0
0   0   255 255            0   255 0   255
0   0   255 255            255 0   255 0

Both contain eight zeros and eight values of 255. Therefore both have mean 127.5, population variance 16256.25 and population SD 127.5. Every histogram bin count is the same. Yet A has two solid blocks while B alternates. A function using only the histogram cannot distinguish them. Their arrangement contains the missing information.

Core · Compare a mean gap with the spread: Cohen's d

A raw foreground–background gap needs context. A difference of 12 intensity units is substantial relative to an SD of 3, but small relative to an SD of 60. A standardised mean difference expresses that gap in spread units.

For the pooled-SD version of Cohen's \(d\), define foreground sample size \(n_f\), mean \(\bar{x}_f\), sample SD \(s_f\), and corresponding background quantities \(n_b,\bar{x}_b,s_b\). Then

\[ s_p^2=\frac{(n_f-1)s_f^2+(n_b-1)s_b^2}{n_f+n_b-2}, \qquad d=\frac{\bar{x}_f-\bar{x}_b}{s_p}. \]

The denominator combines variances, weighted by their degrees of freedom, before taking a square root. It is not the ordinary average of the two SDs. This pooled description uses a common within-group spread; if spreads differ greatly, show both distributions instead of allowing one pooled number to hide that difference.

Work through these invented summaries:

Group n Mean Sample SD Sample variance
Inside mask 4 96 6 36
Chosen background 7 78 12 144
  1. Foreground contributes (4−1) × 36 = 108 squared-deviation units.
  2. Background contributes (7−1) × 144 = 864.
  3. Total degrees of freedom are 4+7−2 = 9.
  4. Pooled variance is (108+864)/9 = 108.
  5. Pooled SD is sqrt(108) ≈ 10.392.
  6. The mean gap is 96−78 = 18, so d = 18/10.392 ≈ 1.732.

The sign is positive because the inside is brighter on average. Reversing the groups reverses the sign. Magnitude is the gap in pooled-SD units; it is neither a probability nor a predicted segmentation score. Conventional small/medium/large labels, when used, are descriptive heuristics rather than thresholds proving a detector will work.

def pooled_d(mean_f, sd_f, n_f, mean_b, sd_b, n_b):
    if n_f < 2 or n_b < 2 or sd_f < 0 or sd_b < 0:
        raise ValueError("Need two samples per group and nonnegative SDs")
    pooled_var = ((n_f - 1) * sd_f**2 + (n_b - 1) * sd_b**2) / (n_f + n_b - 2)
    if pooled_var == 0:
        return np.nan  # undefined standardised difference
    return (mean_f - mean_b) / np.sqrt(pooled_var)

assert np.isclose(pooled_d(96, 6, 4, 78, 12, 7), np.sqrt(3))

If both groups have zero within-group spread, this particular standardisation is undefined. Two different constant intensities could be perfectly distinguishable, but still have an undefined pooled d. Adding an arbitrary epsilon would hide that issue by manufacturing a very large finite number.

Core · Interpret a contrast measurement without overclaiming

Small \(|d|\) means small mean separation relative to the chosen pooled spread. It does not prove that full histograms overlap almost completely, that colour is useless or that texture is the only possible cue. The equal-mean examples above already disprove those stronger conclusions.

Large \(|d|\) also does not prove a global threshold works on new images. One camera exposure might make everything brighter. A foreground distribution can have a shifted mean but a long tail overlapping background. Rectangular regional annotations can include uninformative interior gaps. Inspect distributions and held-out predictions before selecting a decision rule.

For the cloud practice data, organisation regions are not exact silhouettes of bright clouds. A labelled area can include darker spaces between clouds. Therefore brightness statistics describe the supplied region and background definition; they do not turn brightness into ground truth.

Choose and record an aggregation rule. Pooling all foreground pixels across images gives large regions more influence. Calculating a d per image and averaging gives each eligible image equal weight, but can exclude images without both groups and can be unstable for tiny groups. Neither is automatically preferable. Report the eligible-image count, group definition, intensity conversion and aggregation together.

Neighbouring pixels are correlated: a million adjacent locations are not a million independent manufactured items or scenes. A descriptive pixel statistic can still be useful, but uncertainty based on independent-pixel assumptions can be far too optimistic. For repeated-image evidence, preserve the independent source groups discussed in Guide 6. Do not turn pixel count into a claim of enormous experimental support.

Core · Scaling values is different from adding evidence

Suppose the same transformation \(x'=ax+b\), with \(a>0\), is applied to every value in both groups. The mean difference becomes \(a(\bar{x}_f-\bar{x}_b)\); each SD and the pooled SD become \(a\) times their originals. Consequently,

\[ d'=\frac{a(\bar{x}_f-\bar{x}_b)}{a s_p}=d. \]

Adding 20 to both means above changes them to 116 and 98; their gap stays 18 and d stays 1.732. Multiplying every value by 0.5 halves both gap and pooled SD, again preserving d. Dividing a confirmed 8-bit image by 255 is another such uniform scaling.

These statements assume no clipping or rounding loss and the same transform in both groups. With negative a, the sign reverses; with a zero, all values collapse and the SD is zero. Saturating transformed values into 0–255 can destroy the invariance. Independently normalising each region is a different operation and may remove the very mean difference you intended to measure.

Contrast enhancement can help a person see existing structure or help a limited model use it. It cannot guarantee better prediction. CLAHE, contrast-limited adaptive histogram equalisation, uses local histograms with a clipping control rather than one global affine rule. Its mapping depends on neighbourhoods, so the d-invariance proof does not apply. It can change distributions and strengthen noise as well as useful structure. The OpenCV CLAHE explanation describes this local procedure.

For an enhancement experiment, preserve the masks, split and evaluation grid; state settings and compare held-out errors under the same budget. Display original and transformed views with declared plotting limits. A sharper-looking overlay is a viewing result until prediction evidence supports a stronger claim.

Core · Measure arrangement with neighbouring values

Texture describes relationships among values over a neighbourhood: alternation, direction, repeated spacing or local roughness. One simple descriptor is mean absolute horizontal change:

a = np.array([[0, 0, 255, 255]] * 4, dtype=np.float32)
b = np.array([[0, 255, 0, 255], [255, 0, 255, 0]] * 2,
             dtype=np.float32)

def horizontal_change(x):
    return np.abs(np.diff(x, axis=1)).mean()

assert np.isclose(horizontal_change(a), 85)
assert np.isclose(horizontal_change(b), 255)

A row of A has differences [0,255,0], averaging to 85. Every adjacent pair in a row of B differs by 255. axis=1 means “compare columns”; abs removes the direction of the change. Casting before subtraction is essential. With unsigned bytes, 0−255 can wrap to a small positive value rather than become −255.

A directional difference is a simple gradient feature. Rotate A by 90 degrees and its horizontal differences become zero, even though its horizontal boundary is still visible through vertical differences. This feature is direction-sensitive. B remains alternating after a quarter-turn. Combining directions supplies additional information, but does not create a complete semantic classifier.

Local variance is another descriptor. In a three-value window [0,0,0], variance is zero; [0,255,0] has mean 85 and population variance 14450. A sliding variance map can highlight mixed neighbourhoods. Edges, sensor noise and meaningful texture can all raise it. Window size changes its meaning: a tiny window sees detail; a large one can mix several different regions. Keep border handling explicit, because padding also changes the neighbourhood.

Optional depth · From neighbouring pixels to a receptive field

The starter RGB model in Guide 7 sees one pixel's colour. A 1×1 convolution also combines channels at one location, without directly seeing surrounding locations. Identical RGB values therefore receive identical outputs in that starter model.

A 3×3 spatial convolution can respond to an arrangement of nearby pixels. Stacking three stride-1, undilated 3×3 layers gives a theoretical receptive-field width 1 → 3 → 5 → 7. Each output can depend on a 7×7 region of the input away from boundary complications. For a layer with kernel width k, dilation d, stride s and previous input jump j, the recurrence is r_new = r_old + (k−1)*d*j, j_new = j*s.

This describes possible dependence, not a guarantee that training uses all that context well. Downsampling expands context but can erase thin detail. A larger receptive field can help distinguish a repeated background pattern from an isolated disturbance, while still requiring correct labels and held-out evidence.

Optional depth · A tiny co-occurrence matrix

A grey-level co-occurrence matrix, or GLCM, counts pairs of intensity levels at a declared offset. Reduce A and B to levels 0 and 1 and count rightward neighbours. A has four 0→0, four 0→1 and four 1→1 pairs. B has six 0→1 and six 1→0 pairs. Both have 12 pairs, but different pair distributions.

After dividing by 12, the descriptor sum(P[i,j]*(i−j)**2) is 1/3 for A and 1 for B. This distinguishes them even though their single-pixel histograms match. Offset, direction, grey-level quantisation and whether counts are symmetrised must be stated. The scikit-image GLCM documentation gives the formal API. This is an optional descriptor exercise, not a required preprocessing pipeline.

Practice · Check a measurement and challenge a claim

  1. For [8,10,12], calculate mean, population variance and sample variance. Explain why the two variances differ.
  2. Inside mean 84 and background mean 72 share pooled SD8. Find d, its sign and its units. Does that number alone establish a useful threshold?
  3. Apply x'=2x+5 to both groups in question 2 without clipping. Predict the new mean gap, pooled SD and d.
  4. A student reports d=0 from pooled pixels and concludes that their regions have identical appearance. Give two alternative explanations and one further check.
  5. Shuffle the entries of A. Which of mean, histogram and horizontal change must remain fixed? Which might change?
  6. A contrast transform raises validation recall but also raises false alarms. What else must be inspected before calling it useful?
Hints and worked explanations
  1. Mean 10; squared deviations 4,0,4. Population variance 8/3; sample variance 8/2=4. Their divisors encode different conventions.
  2. d=(84−72)/8=+1.5, a dimensionless positive mean difference. Show distributions and held-out errors before claiming separability.
  3. Mean gap 24, pooled SD16, so d remains 1.5. The shared positive affine scale cancels.
  4. The groups might differ in spread/tails, or in spatial arrangement; image-specific brightness shifts could also cancel when pooled. Compare overlays, per-image histograms and neighbourhood features.
  5. Mean and histogram remain fixed because the values are unchanged. Horizontal change may vary because neighbours changed.
  6. Inspect precision/empty-pair behaviour, class support and the declared objective under the fixed split. Improved recall alone does not establish a better operating point.

Transfer question: specify an intensity quantity, a background definition, an aggregation rule and a spatial feature you would inspect on a new dataset. State what each could support and what it could not establish. Leave actual class conclusions to your own checked measurements.
