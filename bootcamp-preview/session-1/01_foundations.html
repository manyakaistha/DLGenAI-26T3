1 · A notebook, an image and a tensor

Core question: what object am I holding, and what does each axis mean?

An ML system uses examples of an input and a target to learn a prediction rule. For image segmentation, the input is an image and the target tells us which locations belong to each label. Training adjusts a rule using training targets. Validation checks that rule on held-out targets. A score describes those predictions; it is not the rule itself.

You do not need to write a neural network today. First learn to read the objects it would receive.

Core · Read a notebook in order

A notebook contains Markdown cells for explanations and code cells for execution. The kernel is the running Python process. Variables remain in its memory until it restarts. A saved output can therefore show an older result than the code above it.

Use this routine in the foundations notebook:

  1. Read a cell and predict its result before running it.
  2. Run the setup and imports first. An import makes a library available; it does not load a dataset.
  3. Run the next cell and inspect the output.
  4. Change only one small value, then explain what changed.
  5. Before considering the notebook reproducible, restart the kernel and run every cell from the top.

NameError often means a definition cell did not run. FileNotFoundError means the selected path is unavailable, not that the data contains no examples. A shape assertion failing means the code's assumptions need attention. Read the final line of the error, identify its cell, and inspect the object immediately before the failing operation.

Core · An array is a numbered arrangement

import numpy as np

image = np.array([
    [0, 64, 128, 255],
    [10, 70, 140, 240],
    [20, 80, 150, 230],
], dtype=np.uint8)

print(image.shape)       # (3, 4): height first, width second
print(image.dtype)       # uint8: nonnegative 8-bit integers
print(image[1, 2])       # 140: row 1, column 2
print(image[:, 2])       # the third column, all rows

Python counts from zero. Row 1 is the second row. A colon means “take all entries on this axis”; a slice 0:2 takes indices 0 and 1 and stops before 2. A scalar is one number. A vector is a sequence. A two-dimensional array is a grid. A tensor generalises this idea to any number of axes; “tensor” does not automatically mean a GPU object or an image.

The grid above has 3 rows × 4 columns = 12 numbers. Its shape records axis lengths. Its dtype records how each number is stored. Neither property tells us what the numbers mean: we supply that interpretation.

Core · Image channels and mask channels mean different things

Object Example shape What the axes mean
Grayscale image (H, W) One intensity per location
RGB image from an image reader (H, W, 3) Red, green and blue values per location
RGB image for a common PyTorch convention (3, H, W) The same channels with a different axis order
Four binary class masks (4, H, W) Four yes/no target questions at each location
Batch of two RGB images (2, 3, H, W) Two examples, then channels, height, width

H and W are placeholders, not values to type literally into a shape. A batch collects examples for one model call. RGB's three channels describe colour; four target channels describe labels. The model can therefore accept three input channels and produce four target scores. These channel counts need not match.

Reordering axes is different from reshaping. If an array is (H, W, 3), np.moveaxis(rgb, -1, 0) moves the colour axis to the front. Simply reshaping to (3, H, W) rearranges which numbers occupy colour and spatial positions. Inspect a known pixel before and after conversion. NumPy's reshape documentation describes its indexing-order behaviour.

Core · A mask is an answer, not a dark photograph

mask = image >= 128
print(mask.dtype)       # bool: True or False
print(mask.sum())       # 6 foreground locations
print(image[mask])      # intensities only where the mask is True

This is an invented brightness rule for demonstration. A real annotation can mark a dark region, a bright region or a texture. Its binary values still mean membership, not brightness. A mask can be empty: every entry is false. Empty does not mean “the image file is missing”.

When displaying a binary mask, use fixed display limits, for example vmin=0, vmax=1. Auto-scaled plots can make a tiny numerical difference look like a large visual difference. Keep images and masks separate so that displaying an overlay never modifies the source values.

Core · Convert intensity values deliberately

For a confirmed 8-bit image, this maps the available intensity range to 0–1:

x = image.astype(np.float32) / 255.0
assert x.shape == image.shape
assert 0.0 <= x.min() <= x.max() <= 1.0

The astype changes storage type. Division changes scale. A stored value of 128 becomes about 0.502. This is a brightness value on a chosen scale; it is not a 50.2% probability of a defect.

Standardisation is a different operation: z = (x - mean) / std. It shifts and rescales values and can produce negative numbers. If mean/std are estimated from a dataset, estimate them from the training partition and reuse those fixed values for validation. Dividing by a known sensor maximum such as 255 does not estimate a statistic from held-out images. Confirm the actual bit depth and range before using this rule; not every image format is 8-bit.

Do not apply image normalisation to a binary target. A target value of 1 means present, not a maximum brightness needing division by 255. A mask accidentally scaled to 1/255 no longer contains the intended binary values.

Checkpoint · Explain before running

  1. What is image[0, 3]? What is image[0:2, 1:3].shape?
  2. An image has shape (96, 144, 3). Which axis contains colour? What should a channel-first version's shape be?
  3. A batch of five images has shape (5, 3, 96, 144). Why is it not five masks?
  4. Why can an empty binary mask still have shape (96, 144)?
Hints and explanations
  1. The top-right value is 255. The slice takes two rows and two columns, so its shape is (2, 2).
  2. The last axis contains three colour values; channel-first is (3, 96, 144). Move axes rather than reinterpreting the buffer.
  3. The first axis counts examples and the second describes RGB input values. Shape interpretation comes from the data contract; target channels are a separate object.
  4. Shape tells us how many locations exist. Empty tells us none of them are marked foreground.

Optional extension · PyTorch tensors

torch.from_numpy(x) creates a PyTorch tensor sharing a compatible NumPy array's storage. A tensor additionally records its device, such as CPU or GPU, and can participate in automatic differentiation. For today, inspect .shape, .dtype and .device; gradients and optimisers belong in the later pipeline session. The PyTorch tensor tutorial provides a small guided introduction.

Transfer question: before reading a new segmentation dataset, list the input shape, input range, target shape and label meaning you need to verify. What error would occur if width and height were exchanged but the total number of pixels stayed the same?
