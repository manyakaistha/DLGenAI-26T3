Milestone 2: Synthetic Pipeline Walkthrough Notebook

This folder contains a standalone, CPU-runnable pedagogical walkthrough of the surface anomaly segmentation pipeline:

  • Jupyter Notebook: synthetic_pipeline_walkthrough.ipynb
  • Paired Python Script: synthetic_pipeline_walkthrough.py

What This Walkthrough Demonstrates

  1. Synthetic Strip Generator: Synthesizes \(128 \times 800\) line-scan steel strips with texture and simulates long-format annotations across four defect classes (defect_a, defect_b, defect_c, defect_d).
  2. PyTorch Dataset Contract: Decodes Fortran column-major RLE strings into a 4-channel binary tensor [4, 128, 800] and loads a normalized single-channel image tensor [1, 128, 800].
  3. Augmentation Alignment Diagnostic: Visualizes and contrasts correct joint transformations against broken, unsynchronized transformations.
  4. Combination Stratification: Groups active defects per image into combination signatures ("clean", "defect_a+defect_c", etc.) to demonstrate guaranteed rare-class representation.
  5. Baseline U-Net Lifecycle: Executes a forward pass, BCEWithLogits loss calculation, backward pass, and optimizer step on a lightweight educational U-Net on CPU.
  6. Post-Processing: Bridges continuous probabilities to discrete decisions via thresholding (\(\tau = 0.5\)) and connected-component minimum area filtering (\(A_{\min} = 50\text{ px}\)).
  7. RLE Encoding: Encodes binary predictions back to 1-indexed Fortran RLE format, including the Kaggle single-space sentinel (" ") for empty masks.

How to Run

Option A: Local Execution with uv

Run the paired Python script directly from your terminal: 

uv run python docs/milestone_2_student_guide/notebooks/synthetic_pipeline_walkthrough.py
Execution takes under 5 seconds on CPU.

Option B: Jupyter Lab / Notebook

Launch your local Jupyter server: 

uv run jupyter lab docs/milestone_2_student_guide/notebooks/synthetic_pipeline_walkthrough.ipynb

Option C: Google Colab

  1. Upload synthetic_pipeline_walkthrough.ipynb to Google Colab.
  2. Select a CPU runtime (no GPU is required for this conceptual walkthrough).
  3. Run the cells in sequential order.
