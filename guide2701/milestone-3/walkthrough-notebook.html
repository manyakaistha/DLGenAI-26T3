Milestone 3: Synthetic Transfer Learning Walkthrough Notebook

This directory contains a self-contained, CPU-runnable educational walkthrough illustrating core concepts from Milestone 3:

  • Jupyter Notebook: synthetic_transfer_learning_walkthrough.ipynb
  • Paired Python Script: synthetic_transfer_learning_walkthrough.py

What This Walkthrough Demonstrates

  1. Synthetic Strip Generation: Synthesizes \(128 \times 800\) line-scan steel strips with texture and simulated defect instances (scratch and inclusion) without requiring competition data.
  2. Pretrained Backbone Feature Taps: Demonstrates how multi-scale feature hierarchies are tapped from a model across downsampling stages (\(/2, /4, /8, /16\)).
  3. Grayscale Input Adaptation: Numerically executes and compares three adaptation strategies (3-channel repetition, first conv weight averaging/summing, and a learned \(1\times 1\) adapter).
  4. Output Head Semantics: Evaluates 4-channel independent sigmoid vs 5-channel mutually exclusive softmax on competing defect logits.
  5. Loss Function Comparison: Computes BCEWithLogitsLoss and Soft Dice loss on synthetic masks, showing how each loss responds to missed defects and false alarms.
  6. Controlled Training Step: Runs a single forward and backward optimization step on a toy encoder-decoder on CPU in under 2 seconds.

How to Run

Option A: Direct Terminal Execution with uv

uv run python docs/milestone_3_student_guide/notebooks/synthetic_transfer_learning_walkthrough.py
Runs on CPU in ~3 seconds.

Option B: Local Jupyter Lab

uv run jupyter lab docs/milestone_3_student_guide/notebooks/synthetic_transfer_learning_walkthrough.ipynb

Option C: Google Colab

  1. Upload synthetic_transfer_learning_walkthrough.ipynb to Google Colab.
  2. Select a standard CPU runtime (no GPU needed).
  3. Execute the cells in sequential order.
